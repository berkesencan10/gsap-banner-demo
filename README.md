# GSAP rich-media banner demo

Two sizes (300×250, 728×90) of an interactive ad for a fictional e-bike brand.
Plain HTML, CSS and ES6 JavaScript, animated with one GSAP timeline per banner.

- Staggered text, rolling wheels, `back.out` price-tag pop, repeating CTA pulse
- Click-out URL with UTM parameters and simulated tracking events (impression, anim_complete, hover, click, replay)
- Honors `prefers-reduced-motion`, keyboard accessible (Enter / Space)

Open `index.html` in a browser. GSAP 3.12.5 is loaded from cdnjs.
The brand, price and dealer are fictional.
