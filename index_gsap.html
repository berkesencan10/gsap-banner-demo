What this demonstrates

  • One gsap.timeline() per banner: staggered text, rolling wheels, back.out price tag pop, repeating CTA pulse.
  • Same animation code reused for two layouts; only CSS positions differ.
  • Click-out URL with UTM parameters and simulated tracking events (impression, anim_complete, hover, click, replay).
  • Respects prefers-reduced-motion (shows the final frame), keyboard accessible (Enter / Space).

The brand, dealer and price are fictional. In a real campaign the tracking calls would fire pixels or the ad server's click macro instead of writing to this log.
